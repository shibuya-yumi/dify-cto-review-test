# プロジェクト進捗サマリー

## 🎯 **プロジェクトの目的**
- GitHub PRに`cto-review`ラベルが付いたら、`outline.md`ファイルをCTOの視点でレビューするbotを作成
- Dify APIを使ってAIによるレビューコメントを自動生成
- PRに自動でコメント投稿

## ❌ **現在の課題**

### **1. GitHub Actions IPブロック問題**
- **問題**: GitHub ActionsのIPアドレスがDifyのWAF（Web Application Firewall）でブロックされている
- **症状**: ローカルでは成功するが、GitHub Actionsでは403 Forbiddenエラー
- **原因**: GitHub ActionsのデータセンターIPがDify側でブロックされている

### **2. 社内VM環境の制約**
- **VM情報**: CentOS 7.6.1810 (d-tb-d035)
- **アクセス**: 踏み台サーバー経由（直接SSH不可）
- **Node.js**: v8.4.0（古すぎる）+ ndenv権限問題
- **Python**: python3コマンドなし
- **制約**: 各種開発環境のインストールに権限問題
